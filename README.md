# Aarhus_soup

Interactive budget model for **A Night Out with Aarhus Improv**: sliders for places, facilitators, back office, venues, food, marketing, ticket price and frequency, with switches for frivillig forening status, moms registration and honorarium vs payroll.

Open `index.html` in a browser, or view it on GitHub Pages once enabled.

Starting values are placeholders, not quotes. Planning aid, not tax advice.
